# 烧录与验收

使用根目录 `DWIN_SET`；`GUI\DWIN_SET` 同时保留了 DGUS 编辑所需的源 BMP，根目录下载包只包含需要下载的 9 个文件。

## 下载文件

| 文件 | 作用 | 图片 Flash 位置 |
|---|---|---|
| 13TouchFile.bin | 44 个触控按钮定义 | 固定 13 |
| 14ShowFile.bin | 218 个显示控件及页面索引 | 固定 14 |
| 22_Config.bin | 初始 VP 数据 | 固定 22 |
| 32_Pages.icl | 26 张 800×480 页面，含登录页和开机帧 | 32—38 |
| 40_Tiles.icl | 48 张地图、角色与头像 | 40 |
| 48_HUD.icl | 88 张数字、文字、对话与登录图标 | 48 |
| 50_Music.wae | 4 段 EKT043E 蜂鸣器优化配乐，2,510,848 字节 | 50—59 |
| T5L51.bin | Keil 生成的 OS CPU 8051 应用 | 用户 8051 程序区 |
| T5LCFG.CFG | 启动图片库、方向、报点等 | 系统配置 |

ICL 为 RGB24 源图、JPEG 90%、4:4:4。最大单图 82,186 字节，低于 EKT043E/T5L0 的 248 KB 限制；库之间没有重叠。完整字节数与 SHA-256 在 `download_manifest.json`，每次构建都会更新。

CFG 主要值：0x05=0x60（加载 22、WAE 音乐模式、横屏 0°，关闭自动触摸伴音）；0x07=0x32（WAE 库 50）；0x06=0（不擦除整片 Flash、不启用加密）；0x08=0x20（背景库 32）；0x09=0x14（20 Hz 报点）；0x0A=0x001C（115200）；亮度 100%。EKT043E 虽然只有板载蜂鸣器，这里仍须保持音乐模式，才能播放具有不同音高的蜂鸣器优化 PCM；普通蜂鸣器模式只能控制鸣叫时长。

十五层版本使用 320 字节 v2 存档。旧 5 层 v1 存档会自动判为无效，首次运行请在登录后选择“新的冒险”。

包内不含 `T5L_UI` / `T5L_OS` 底层固件：使用原有可运行 DGUS2 和 8051 用户程序的屏幕底层。屏幕型号、分辨率或图片存储容量不同时，应先适配资源地址与布局。

## 下载步骤

1. 准备已格式化为 FAT32、分配单元 4096 字节的 SD 卡。格式化会删除卡内文件，如需格式化先自行备份。
2. 将本项目根目录的 `DWIN_SET` 整个复制到卡根目录。卡中不要同时混入同学项目的同号资源文件。
3. 屏幕断电，插卡，上电，等待下载界面完成。
4. 断电，拔卡，再上电。应先播放校徽与魔塔元素的约 3 秒动画，再进入登录页。首次读取存档及屏幕启动可能增加开机等待时间。

如出现“存档失败”，先确认屏幕底层支持 0x0008 NOR 数据库接口；该界面不会把失败显示成成功。存档使用 NOR 字地址 0x020000 与 0x021000 两个槽，CRC 校验后才切换有效槽。两个位置是用户数据库，需确保其他运行程序没有使用它们。

EKT043E 板载蜂鸣器不能清晰还原普通全频音乐，本项目因此使用单音高频方波版本。无声时先检查 `50_Music.wae` 是否下载成功、CFG 的 0x05 bit6 是否为 1、0x07 是否为 50，以及游戏音量是否关闭。若有声但不同音高响度差别明显，请记录最响的音符区间，再在 `Tools\build_audio.py` 中整体调整 `TONE_MIN/TONE_MAX`；不要切换为只能控制固定鸣叫时长的蜂鸣器伴音模式。

黑屏先检查 `32_Pages.icl` 是否下载、CFG 的 0x08 是否为 32；界面正常但按键无反应时，检查 T5L51.bin 是否下载、屏幕是否支持用户 C51 应用。触摸位置整体偏移时检查实际分辨率与方向，保持出厂触摸配置。

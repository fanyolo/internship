# 地址与代码说明

VP 按 **16 位字地址** 计数，发送数据采用大端字节序。`sys_write_vp(vp, buf, n)` 的 n 是字数，缓冲区需要 2n 字节。显示控件 SP=0xFFFF，固定描述不转存到用户 VP。

| VP | 字数 | 内容 |
|---|---:|---|
| 0x1000 | 1 | 按钮事件，OS 读取后写零 |
| 0x1100 / 1110 / 1120 / 1130 | 每组 4 | 生命 / 攻击 / 防御 / 金币，各位十进制数字图标 |
| 0x1140 | 3 | 经验 |
| 0x1150 | 6 | 黄、蓝、红钥匙，各 2 位 |
| 0x1160 | 2 | 随身药水数量 |
| 0x1170 / 1171 | 各 1 | 水晶剑、秘银盾是否获得 |
| 0x1190—0x1191 | 2 | 当前楼层 01—15 |
| 0x11A0 | 4 | 用时 MMSS |
| 0x11B0 / 11C0 | 2 / 4 | 击败数量 / 移动步数 |
| 0x1200 / 1210 / 1220 / 1230 / 1240 | 每组 4 | 当前手册敌人的生命、攻防、金币、预计损血 |
| 0x1300 | 1 | 提示编号 0—23，映射 HUD 图标 20—43 |
| 0x1310 | 1 | 敌人编号 0—5，头像映射 40—45，名称映射 10—15 |
| 0x1320 | 1 | 对话编号 0—1，映射 HUD 图标 70—71 |
| 0x1330 | 1 | 音量档位 0—3，映射 HUD 44—47 |
| 0x1340 | 1 | 生命不超过 120 时闪烁，映射 HUD 48—49 |
| 0x1350—0x1353 | 4 | 上下左右按键反馈，分别映射 HUD 50—57 |
| 0x1360—0x1365 | 6 | 登录账号的 6 个数字图标，空位为 0，数字 0—9 映射为 1—10 |
| 0x1370—0x1375 | 6 | 登录密码的 6 个掩码图标，空位为 0、圆点为 11 |
| 0x1380 | 1 | 登录提示：输入账号、输入密码、不完整、验证失败 |
| 0x00A0—0x00A3 | 4 | 系统 WAE 播放接口；本项目写前 2 字，读取 0x00A1 低字节的播放状态 |
| 0x2000—0x2078 | 121 | 11×11 地图图标，行优先；每格 32×32 |
| 0x3000—0x309F | 160 | NOR 存档传输缓冲区 |

完整控件坐标、页面、图标库和键值见 `VP_控件明细.csv`。数字 VP 中存的是某一位数字，不是完整属性值；例如生命 1987 对应 0x1100—0x1103 写入 1、9、8、7。

## 页面

0 初始页；1 首页；2 地图；3 手册；4 商店；5 背包；6 帮助；7 通关；8 暂停；9 对话；10 登录；11—25 开机 / 返回首页 / 换层共用的加载动画帧。首次开机动画结束后进入登录页；会话内返回首页不重复登录。

地图原点 (28,72)，11 列、11 行，格宽高 32。右侧属性和触摸区由背景图片固定排版。每张图片是 RGB24 BMP，ICL 内转换为 baseline JPEG。所有图标采用“显示背景”模式，更新时覆盖旧图，避免人物和数字残影。

## 代码分工

- `tower.c`：游戏状态、移动、开门、战斗、成长、界面状态、存档编码。
- `levels.c`：3 套地图模板与路线，只读 code 存储；15 个逻辑楼层按 A→B→C 循环。
- `view.c`：游戏属性到页面编号、VP 图标编号的统一映射。
- `audio.c`：同源音乐状态调度，曲目切换、播放结束后循环、静音与暂停降音量。
- `main.c`：T5L OS 入口、DGUS 读写、50 ms 循环、页面切换、变化控件刷新、NOR 双槽读写。
- `sys.c` / `T5LOS8051.h` / `STARTUP_M5.A51`：由同学项目中的 DWIN 底层例程整理；共享中断计数器加 volatile，保留 T5L 8051 启动签名。
- `PC_Preview\bridge.c`：同一 C 引擎的 PC 导出接口；`Preview.cs` 负责按同一控件表绘制界面与电脑文件存档；`Music.cs` 负责应用内 PCM 音量和 Windows 播放。

战斗损血 = (ceil(怪物生命 / (玩家攻击 − 怪物防御)) − 1) × max(怪物攻击 − 有效玩家防御, 0)。法师使用玩家防御的一半，其他怪物用完整防御；攻击不足或损血 ≥ 生命时禁止开战。

存档升级为 v2、固定 320 字节，含版本、序号、属性、15 位已访问/机关状态、240 字节逐层清除位图和 CRC16。旧版 5 层 v1 存档与新地图结构不兼容，会自动判为无效。存档槽使用片内 NOR **字地址** 0x020000 与 0x021000，相隔 8 KB；每次写另一个槽并回读比较，校验成功才更新有效序号。开机选择最新且校验有效的一份，电脑端采用同样编码。

参考同学工程学习了 DGUS 页面、触控按钮、VP 显示与 OS 主循环的配合方式；新工程独立设计了魔塔地图、状态机、保存格式和素材编号，没有复用他们的战斗角色图片或关卡。

## 加载与音乐状态

`boot_target` 决定加载后进入登录页、首页还是地图。首次启动目标为登录页；楼梯或传送更新楼层后设置目标为地图；返回首页先等待 `tower_saved` 成功回调，再启动目标为首页的加载。页面为加载状态时忽略所有键值。`home_request` 等待期间也锁定操作，保存失败清除此请求并保留当前页。

WAE 曲目编号为 0 启动、1 探索、2 最终层、3 通关。硬件写 0x00A0 两字：`曲目, 01, 音量, 00`；音量 0—64。0x00A1 低字节反馈 2 表示播放中；循环曲目结束后重新发起，切换后留 6 个 tick 的反馈等待时间。音量档位对应 0、32、52、64，暂停再除以 2。静音采用音量 0，不把只读播放状态误当停止命令。

显示缓存共有 204 个有效字，分配 208 字，覆盖地图、双位楼层、状态、登录、音量、低血量和方向反馈 VP。资源库的 Flash 编号与 VP 是不同地址空间；WAE 50—59 不占用 VP 0x3000 存档缓冲区。
